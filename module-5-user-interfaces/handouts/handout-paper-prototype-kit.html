Paper prototype kit: screens

ASM 532: Introduction to Ag Informatics · Module 5, Lecture 5.2 · ankita@purdue.edu

Each screen is a browser window with Bootstrap's 12-column grid. Cut out pieces from the back of another copy. Every piece is sized in columns, so place it on the columns it covers: it will take the same space on screen in code. Draw anything the kit doesn't have, on the grid. One view per screen; use your second copy for more.
