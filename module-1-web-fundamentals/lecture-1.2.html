Software Development Toolbox

  • View and access web content:
    • Web Browser e.g., Firefox Chrome, etc.

  • Programming languages to "markup" content:
    • Structure and place content on a web page: HTML
    • Visually style content: CSS

  • Write and edit code:
    • Editor or Integrated Development Environment (IDE) e.g., VS Code

  • Store, manage, and track changes via a "repository" or "repo":
    • Command line utility e.g., git, svn, etc.
    • Code Hosting Service e.g., GitHub, Gitlab, etc.

About the Lab

GOTO: Module 1, Lab 1

In-Class Activity -> Lab 1 [30 mins]

  1. Scope
    • What is the goal of your website?
    • What content do you want to showcase?
  2. Sketch
    • Draw a few single-page layouts
    • Mix and match till you get a page layout that you like
  3. Atomize
    • What are the basic components that you need?
  4. Pseudocode -- submit in-class today!
    • Draw a clean layout
    • In simple language: label the components

  5. Refine & Translate -- Continue in Step 5 of the Lab
    • Check your dictionary and cheatsheet
    • For each component: find the respective HTML element
    • For each reusable "aesthetic" choice: find CSS styles
    • Write your code! Tinker, test, refine, test, ship!
